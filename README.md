### What I'm building

I don't just define products. I build them, ship them, and watch what happens next.

**Keepr** — *Capture anything. Find everything.*
A personal memory workspace for capturing and retrieving notes, links, screenshots, images, PDFs, and quotes. It started as an earlier discovery concept and evolved from there. I ran the discovery myself — 20+ interviews to understand where existing note-taking and bookmarking tools break down — then defined the problem, scoped the MVP, and made the UX and prioritization calls. Built through AI-assisted development, tested through UAT, and shaped by real user feedback across iterations. Live today as an installable PWA with Google and email authentication.

**NewsRadar** — *Personalised, quiet news. Less doom-scroll, more signal.*
A news briefing tool built around a simple bet: most news consumption is noise, not signal, and people don't need more headlines — they need fewer, better ones, delivered without the scroll. Currently in build, not yet live. Same loop as Keepr: figure out the real problem first, then build toward it.
